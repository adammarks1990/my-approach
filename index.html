A three-minute tour

An interactive first-90-day plan for People Operations, with the working tools behind it. Scenario: the Oct 1–15 payroll, planned for release Oct 14.

  1. 90-day planWhat gets done when, and what counts as proof that it’s done.
  2. OperationsThe Oct 15 payroll is blocked. See which findings are behind it and how they link.
  3. ReconciliationFix Daniel Brooks’s missed promotion: request the correction, then verify the amount.
  4. RequestsSubmit an accommodation request and see how it’s routed privately.

Where these sit in the build order

  1. Days 1–30Operations view, reconciliation, obligations calendar and data-quality checks. Protect people and get visibility while learning the operation.
  2. Days 31–60Request intake with private routing, written playbooks and verified lifecycle checklists. This is the standardization step.
  3. Days 61–90Metrics agreed with Finance, automated checks and alerts, and a review of access and role-based views.
  4. After 90 daysSelf-service and an AI assistant, once playbooks are reliable and request data shows the most common questions.

Build or configure: most of this lives inside the existing HRIS, payroll provider, ticketing tool and Slack. The first step is finding which of these capabilities already exist and which are underused.
